<p class="width-40 issue-lead sec-title">
本サイトの<br>問題提起
</p>

<p class="width-40 margin02 agree-gap">
問題にしているのは、通報を受けてからの会社の対応です。<b><span class="text-warn">通報の後、通報者は通報内容に関する情報から遮断されました。そのうえで、裏づけの確認できない情報を知らされました。</span></b>このように、社内外で「コンプライアンスの再徹底」を掲げるＥＮＥＯＳでさえ、適切な窓口対応ができていません。
</p>
<p class="width-40">
本サイトは、社内通報窓口を利用した従業員（以下「通報者」）が作成しています。
</p>

<p class="larger width-40 margin02 agree-gap bar-title">
調査事項を曖昧にして回答
</p>
<p class="width-40">
通報したのは、豪州企業からの請求書に含まれていた海外消費税（ＧＳＴ）を「支払う必要がないのに払っている」という問題でした。ところが、会社が伝えた調査事項は曖昧で、肝心の「支払う必要があるか否か」は調査結果として示されませんでした。
</p>
<p class="larger width-40 margin02 agree-gap bar-title">
裏づけが確認できない情報
</p>
<p class="width-40">
その後、会社は通報者に「法改正があったため」と知らせ、海外子会社は「本社の代わりに返金を受けた」として本社に送金しました。しかし、その「法改正」は未だに特定できず、返金を受けた事実も確認できません。この送金の会計処理には疑問が残ります。
</p>
<p class="larger width-40 margin02 agree-gap bar-title">
海外消費税の支払を契約化
</p>
<p class="width-40">
契約書には、ＥＮＥＯＳが海外消費税を支払うという定めはありませんでした。会社は通報を受けた後、契約を「海外企業がＥＮＥＯＳへ海外消費税を請求できる」形へ変更しました。この措置は通報者に知らされませんでした。
</p>

<p class="width-40 gap-6">
<b><span class="text-main">裁判所の判断 <i class="fa-solid fa-hand-point-right"></i> </span></b>　会社は通報を受けた後に契約を変更しましたが、<b>その是正措置を通報者に通知しませんでした。これが裁判の争点です。</b>裁判所は、通知しなかったことを問題にする主張を退けました。
</p>
<p class="width-40 margin02">
契約書に海外消費税の定めはありませんでした。しかし裁判所は、ＥＮＥＯＳが取引先と「海外消費税を支払う合意」をしていたと推認しました。合意がある以上、海外消費税の支払は契約違反ではない、というのが裁判所の考えです。違反そのものがなければ、通報者に伝えるべき「違反への是正措置」もない ── そう結論づけました。
</p>

<div class="agm-section" markdown>

<p class="sec-title">
<span class="text-main">裏づけが<br>確認できない<br>3つの情報</span>
</p>

<p class="width-40 verdict-lead">
裁判では敗訴しました。けれども、裁判を通じて、ＥＮＥＯＳが通報者に次の3つを知らせていた事実が明確になりました。
</p>

<p class="width-40 margin04 bar-title">
<span class="larger">法改正があったため</span><br>
ただし、その法改正は未だに特定されていません
</p>
<p class="width-40 margin02">
会社は通報者に、「法改正があったため」と知らせました。<br>
── しかし、その「法改正」が、いつの・どの法律なのか、未だに特定されていません。（通報者が探しても、見つかりませんでした。）
</p>

<p class="width-40 margin04 bar-title">
<span class="larger">子会社が返金を受けた</span><br>
ただし、記録は「子会社 <i class="fa-solid fa-arrow-right"></i> 本社」間の送金だけ
</p>
<p class="width-40 margin02">
会社は通報者に、「海外子会社が本社の代わりに海外消費税の返金を受けた」ことを解決策として示しました。<br>
── しかし、記録として確認できるのは「海外子会社から本社への送金」だけで、「海外子会社が外部から実際に回収した」ことを示す記録は見つかりません。回収していないのなら、海外子会社は自らの資金で本社の支払を肩代わりしたことになり、送金そのものが問題になります。
</p>

<p class="width-40 margin04 bar-title">
<span class="larger">コンサルに相談した</span><br>
ただし、何を相談したのかが分からない
</p>
<p class="width-40 margin02">
会社は通報者に、「経理部およびコンサルティング会社と相談し」たことを対応の根拠として示しました。<br>
── しかし、何を相談し、どう回答を得たのかは記録に示されておらず、「違反ではない」という結論だけが伝えられました。
</p>

</div>

<p class="width-40 gap-6">
<b><span class="text-warn">こんなことも！？</span></b>　海外消費税の支払いについて、裁判所は「合意による支払い」と推認を示しました。なお、ＥＮＥＯＳ側からは、その「合意」の記録は示されておらず、「記録のない合意」となります。つまり、ＥＮＥＯＳは海外消費税を記録されない合意に基づいて支払っていたことになります。<span class="text-warn">── 「契約書に定めのない海外消費税を、記録されない合意に基づいて支払う」　これ自体が、企業の内部統制として問題です。</span>
</p>

<p class="width-40 gap-6">
会社は通報者に、「法改正があった」「海外子会社が本社の代わりに返金を受けた」と説明しました。しかし、そのどちらにも裏づけが示されていません。<br>
通報を受けた会社は、通報者に事実を説明したのか。本サイトが問うのは、その一点です。
</p>
