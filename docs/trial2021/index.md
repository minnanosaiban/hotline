<p class="width-40 issue-lead sec-title">
2021年提訴<br>判決の概要<br><span class="smaller">（AIによる解説、2026.09）</span>
</p>

<p class="width-40 margin02 lead-normal-gap">
豪州企業からＥＮＥＯＳ宛ての請求書にＧＳＴ（豪州の付加価値税）が含まれていたことと、その還付・会計処理について、通報者は社内のコンプライアンスホットラインに２度通報しました。この通報への会社の対応について、<b>「会社は通報者に対して、通報内容を調査する信義則上の義務を負うか」が裁判の主な争点</b>です。あわせて、通報を理由とする不利益取扱い・パワーハラスメントの有無や、人事評価のあり方も争われました。
</p>

<p class="width-40 margin02">
地裁は、内部通報制度における調査等は、不正行為等を早期に発見・是正して会社の業務の適正化を図るためのものであり、<b>「通報者個人のためにされるものではない」</b>としました。そのうえで、不正行為等によって直接被害を受けた者が通報した場合でない限り、会社は通報者個人に対して当然に調査義務を負うものではなく、原告が通報した不適切会計等は原告が直接被害を受けるものではないとして、請求を退けました。
</p>

<p class="width-40 margin02">
さらに地裁は、この点をおいても、次のように判断しました。<br>
<i class="fa-solid fa-square-full riyu-lead-icon"></i>通報フォームに事実経過として記載しただけの事項や、調査の過程で伝えた疑問は、当然には調査の対象にならない<br>
<i class="fa-solid fa-square-full riyu-lead-icon"></i>調査の具体的な方法は、会社の合理的な裁量に委ねられている（契約書や会計仕訳を確認しなくても不合理ではない）<br>
<i class="fa-solid fa-square-full riyu-lead-icon"></i>業務の移管・業務命令・「グループ内庶務」の業務分担・社内ＳＮＳへの投稿に関する措置は、いずれも通報を理由とする不利益取扱いやパワーハラスメントではない
</p>

<p class="width-40 margin02">
高裁は、業務移管の通知が虚偽であるとの主張と、線形回帰分析を命じた業務命令がパワーハラスメントであるとの主張に応答する補正を加えたうえで、地裁の判断をそのまま引用し、控訴を棄却しました。<b>「調査は通報者個人のためのものではない」という地裁の判断は、控訴審でも維持されました</b>。
</p>
