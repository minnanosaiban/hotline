# ＥＮＥＯＳの内部通報制度をめぐる訴訟について

**https://minnanosaiban.github.io/hotline/**

ＥＮＥＯＳ（エネオス）の内部通報制度をめぐる裁判・訴訟の記録です。判決文・準備書面などの裁判文書と、株主総会2026での質疑応答を掲載しています。裁判文書はすべてテキスト化しています。

本サイトは、社内通報窓口を利用した従業員（以下「通報者」）が作成しています。

## 本サイトの問題提起

問題にしているのは、通報後の会社の対応です。**通報の後、通報者は通報内容に関する情報から遮断されました。そのうえで、存在が確認できないことを事実であるかのように伝えられました。** このように、社内外で「コンプライアンスの再徹底」を掲げるＥＮＥＯＳでさえ、適切な窓口対応ができていません。

### 調査事項を曖昧にして回答

通報したのは、豪州企業からの請求書に含まれていた豪州消費税（ＧＳＴ）を「支払う必要がないのに払っている」という問題でした。ところが、会社が伝えた調査事項は曖昧で、肝心の「支払う必要があるか否か」は調査結果として示されませんでした。

### 事実であるかのように通知

その後、会社は通報者に「法改正があったため」と知らせ、豪州子会社は「本社の代わりに返金を受けた」として本社に送金しました。しかし、その「法改正」は未だに特定できず、返金を受けた事実も確認できません。この送金の会計処理には疑問が残ります。

### 豪州消費税の支払を契約化

契約書には、ＥＮＥＯＳが豪州消費税を支払うという定めはありませんでした。会社は通報を受けた後、契約を「豪州企業がＥＮＥＯＳへ豪州消費税を請求できる」形へ変更しました。この措置は通報者に知らされませんでした。
